# GridFormula 类电子表格公式编辑器

技术栈：Vue 3、TypeScript、Vite、Vuetify、Pinia、Vue Router。

## 功能

- 1000 行、26 列虚拟滚动表格，支持编辑、区域选择、复制粘贴与键盘导航。
- 支持冻结首行、首列。
- 多工作表：底部标签栏可新建、双击改名、菜单复制、拖动排序；空名、重名（不区分大小写）、含 `! : ' " \ / ? * [ ]` 或与单元格引用同名的名称会被拒绝。
- 公式支持四则运算、括号、单元格引用、区域引用、SUM、AVERAGE、MIN、MAX、COUNT、IF、ROUND、ABS。
- 跨表引用：`'华北'!B2`、`华北!B2`、跨表区域 `'华北'!B2:D2`；改名或拖动排序后公式仍指向同一张表（改名时自动同步公式文本）。
- 复制工作表时，指向源表自身的引用会改写到副本，指向其他表的跨表引用保持原目标，不串入副本。
- 基于全工作簿依赖图检测循环引用（含跨表循环），返回 `#CYCLE!` 并令依赖方失效。
- 编辑后只重算直接和间接受影响的公式单元格（含跨表影响面）。
- 撤销重做同时还原工作表结构、公式与计算结果。
- 切换工作表只读取当前页；CSV 导出仅导出当前工作表。
- 旧版单表工作簿数据自动迁移为首个工作表，公式与值保持不变。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```
