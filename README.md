# GridFormula 类电子表格公式编辑器

技术栈：Vue 3、TypeScript、Vite、Vuetify、Pinia、Vue Router。

## 功能

- 1000 行、26 列虚拟滚动表格，支持编辑、区域选择、复制粘贴与键盘导航。
- 多工作表工作簿：底部标签栏可新建、改名、复制、删除工作表，支持拖动排序；双击标签或右键菜单即可改名。
- 公式支持跨表引用，如 `=华北!B2`、`=SUM(华北!B2:B5)`，工作表改名后公式仍指向同一张表（稳定 id）。
- 公式支持四则运算、括号、单元格引用、区域引用、SUM、AVERAGE、MIN、MAX、COUNT、IF、ROUND、ABS。
- 基于跨表依赖图（`工作表id::单元格id`）检测循环引用，跨表循环显示 `#CYCLE!` 并让依赖方失效。
- 编辑后只重算直接和间接受影响的公式单元格（跨表增量）。
- 撤销重做同时还原工作表结构、公式与结果；切换或导出时只读当前页。
- 复制工作表时，副本内指向源表的公式自动改写为指向副本自身，避免跨表引用串到副本外。
- 空名或重名工作表无法建立；旧单表数据迁移为首个工作表，公式与值不变。
- 支持 CSV 导出（仅当前工作表）。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```
